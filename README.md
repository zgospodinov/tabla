# Табла — учи и играй

Уеб приложение за обикновена табла (backgammon) срещу компютъра. Без външни библиотеки и без build.

## Стартиране

```bash
node serve.js
```

После отворете http://localhost:5173

## Режими

- **Тренировка** — компютърът играе бавно, а вие получавате:
  - правилата, които важат точно в този ход (чифт, бар, задължителен ход, изваждане…);
  - всички възможни ходове, подредени по оценка, с плюсове и минуси;
  - цветни подсказки на дъската за всяко място, където може да отиде избраният пул;
  - преглед на хода преди да го изиграете (първо кликване = преглед, второ = изиграване);
  - оценка на изиграния ход и по-добрата алтернатива, плюс обяснения на ходовете на компютъра.
- **Игра** — нормална игра със сила лесно / нормално / трудно, подсказка само при поискване.
- **Стратегии** — пет известни стратегии (бягаща игра, прайм, задържаща игра, блиц, обратна игра) като симулации ход по ход с подробни обяснения. Всеки ход в сценариите се проверява от engine-а.
- **Правила** — пълни правила с диаграми, съвети за начинаещи и речник.

Настройките (сила, темпо, звук, нулиране на резултата) са в бутона ⚙ горе вдясно. Бутонът ⛶ в ъгъла на дъската (или клавиш F) включва режим „цял екран“ в тренировка, игра и стратегии; Esc излиза.

## Структура

- `js/engine.js` — правила, генериране на ходове, оценка на позицията, AI и текстовете с обяснения
- `js/board.js` — SVG дъската
- `js/app.js` — режимите и хода на играта
- `js/rules.js` — страницата с правилата
- `js/sound.js` — звуковите ефекти (Web Audio)
- `js/strategies-data.js` — сценариите на стратегиите; `js/strat-core.js` ги проверява; `js/strategies.js` — екранът за симулации
- `tools/strat-dev.js` — помощник при писане на сценарии: `node tools/strat-dev.js prime`
- `tests/engine.test.js` — тестове на правилата: `node tests/engine.test.js`

Оценката на ходовете е евристична (приблизителна). Тя е добра за учене, но не е на нивото на професионален софтуер за табла.
