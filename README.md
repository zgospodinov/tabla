# Табла — учи и играй

Уеб приложение за обикновена табла (backgammon): срещу компютъра или онлайн срещу приятел. Без външни библиотеки и без build стъпка за самото приложение.

Онлайн: **https://tabla.zdravko-gospodinov.workers.dev**

## Стартиране

```bash
node serve.js
```

После отворете http://localhost:5173. Онлайн режимът не работи така, защото няма сървър за стаите.

За онлайн игра локално (Cloudflare Worker + Durable Objects):

```bash
npm install
```

```bash
npm run dev
```

После отворете http://localhost:8787. За да пробвате двама играчи, отворете стаята в два раздела. Мястото в стаята се пази за всеки раздел.

## Режими

- **Тренировка** — компютърът играе бавно, а вие получавате:
  - правилата, които важат точно в този ход (чифт, бар, задължителен ход, изваждане…);
  - всички възможни ходове, подредени по оценка, с плюсове и минуси;
  - цветни подсказки на дъската за всяко място, където може да отиде избраният пул;
  - преглед на хода преди да го изиграете (първо кликване = преглед, второ = изиграване);
  - оценка на изиграния ход и по-добрата алтернатива, плюс обяснения на ходовете на компютъра.
- **Игра** — нормална игра със сила лесно / нормално / трудно, подсказка само при поискване.
- **Онлайн** — единият играч създава стая и изпраща кода от 6 знака или линка `…/#room-КОД`. Другият влиза с кода. Без регистрация.
  - Сървърът хвърля заровете и проверява всеки ход по правилата, така че никой не може да мами.
  - Настройки на стаята: време за ход (без ограничение, 30 с, 1, 2 или 5 мин) и запис на играта. Когато времето изтече, сървърът изиграва случаен позволен ход.
  - Има реванш, предаване и резултат за стаята. При прекъсната връзка приложението се свързва отново само.
  - Неактивна стая се изтрива след 48 часа.
- **Стратегии** — пет известни стратегии (бягаща игра, прайм, задържаща игра, блиц, обратна игра) като симулации ход по ход с подробни обяснения. Всеки ход в сценариите се проверява от engine-а.
- **Правила** — пълни правила с диаграми, съвети за начинаещи и речник.

Настройките (сила, темпо, звук, нулиране на резултата) са в бутона ⚙ горе вдясно. Бутонът ⛶ в ъгъла на дъската (или клавиш F) включва режим „цял екран“ в тренировка, игра и стратегии; Esc излиза.

## Структура

- `js/engine.js` — правила, генериране на ходове, оценка на позицията, AI и текстовете с обяснения
- `js/board.js` — SVG дъската
- `js/app.js` — режимите и хода на играта (и онлайн играта)
- `js/online.js` — онлайн лобито и WebSocket връзката
- `worker/index.js` — Cloudflare Worker: `/api/rooms` и статичните файлове; `worker/room.js` — стаята (Durable Object), която пази играта и проверява ходовете с `js/engine.js`
- `wrangler.jsonc`, `.assetsignore` — настройки за Cloudflare
- `js/rules.js` — страницата с правилата
- `js/sound.js` — звуковите ефекти (Web Audio)
- `js/strategies-data.js` — сценариите на стратегиите; `js/strat-core.js` ги проверява; `js/strategies.js` — екранът за симулации
- `tools/strat-dev.js` — помощник при писане на сценарии: `node tools/strat-dev.js prime`
- `tests/engine.test.js` — тестове на правилата: `node tests/engine.test.js`

Оценката на ходовете е евристична (приблизителна). Тя е добра за учене, но не е на нивото на професионален софтуер за табла.

Единичният файл за claude.ai артефакта се сглобява с `node build-artifact.js` → `dist/tabla.html`. В него онлайн режимът е скрит.

Качване в Cloudflare: `npm run deploy`.
